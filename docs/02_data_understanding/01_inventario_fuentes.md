## 4. Verificaciones pendientes

Para cada conjunto de datos se deberá confirmar:

- Nombre oficial.
- Entidad publicadora.
- Descripción del conjunto.
- Disponibilidad de la API.
- Pertinencia para los objetivos del proyecto.

No se considerará verificada una API únicamente
por disponer de su dirección.
